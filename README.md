# KeuanganKu — Android Native

Aplikasi keuangan pribadi Android native (Kotlin, minSdk 26).

- **UI**: Jetpack Compose + Material 3
- **Backend**: Supabase (PostgreSQL + Auth + Storage privat)
- **Struk AI**: ML Kit Text Recognition (on-device) → 9Router (OpenAI-compatible)
- **Offline**: Room cache + antrean `dirty-flag`, sinkron otomatis via WorkManager

Lihat **PANDUAN.md** untuk cara build APK di laptopmu.
Konsep lengkap: `KONSEP.md`.
